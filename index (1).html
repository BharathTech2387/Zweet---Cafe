Implementation and Performance Analysis of Interpolation Search

Subject: CS5303 - Design and Analysis of Algorithms
Experiment No: 1

Problem Statement

Given a sorted array of uniformly distributed integers, implement Interpolation Search to find the position of a target element. Compare its performance with Binary Search for different dataset sizes (1000, 5000, 10000, 50000, 100000 elements).

Aim

To implement the Interpolation Search algorithm in Python and analyze its time complexity by measuring execution time on sorted datasets of varying sizes.

Pseudocode

INTERPOLATION_SEARCH(arr, target):
  low ← 0
  high ← len(arr) - 1
  WHILE low ≤ high AND target ≥ arr[low] AND target ≤ arr[high]:
    IF low = high:
      IF arr[low] = target: RETURN low
      ELSE: RETURN -1
    pos ← low + ((target - arr[low]) * (high - low)) / (arr[high] - arr[low])
    pos ← FLOOR(pos)
    IF arr[pos] = target:
      RETURN pos
    ELIF arr[pos] < target:
      low ← pos + 1
    ELSE:
      high ← pos - 1
  RETURN -1  // Element not found

Result

The Interpolation Search algorithm was successfully implemented. It found the target element at index 5 with only 2 comparisons. Performance analysis shows that Interpolation Search consistently requires fewer comparisons (O(log log n)) compared to Binary Search (O(log n)) for uniformly distributed sorted data.

Inference

Interpolation Search outperforms Binary Search when data is uniformly distributed, achieving near O(log log n) complexity. The algorithm is highly efficient for large, uniformly spaced datasets. However, its performance degrades to O(n) for skewed distributions. For real-world applications with uniform data (e.g., phone books), Interpolation Search is the preferred algorithm.
